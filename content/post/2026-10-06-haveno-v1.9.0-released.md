## _Основные моменты_

- Переработаны экраны получения, отправки и сделок, добавлены новый мастер запуска и восстановление кошелька из мнемонической фразы.
- 24 новых способа оплаты в Африке, Латинской Америке, Азии, Европе, Турции и России.
- Комплексное усиление безопасности сделок, споров, сетевого уровня и API.
- Более быстрый запуск, более надёжные синхронизация и восстановление кошелька, сниженное потребление ресурсов процессора и памяти.
- Возвращён клиент API для командной строки, добавлены доступ к API через onion-сервис Tor и новое руководство пользователя по API.

## _Перед обновлением_

- Это обновление не является обязательным, но рекомендуется всем пользователям.
- Арбитры должны обновиться раньше пользователей.
- Перед обновлением сделайте резервную копию директории приложения.
- Пользовательское соглашение было переписано. Существующим пользователям будет предложено принять его после обновления.

## _Пользовательский интерфейс_

- Переработаны экраны получения, отправки и сделок, включая сведения о транзакциях и диалоги подтверждения.
- Добавлен мастер запуска с импортом кошелька, установкой пароля, выбором предпочитаемой валюты, настройкой узла Monero и переключателем светлой/тёмной темы.
- Восстановление кошелька Monero из мнемонической фразы с необязательным указанием высоты или даты восстановления.
- Отображение условий предложения во время оплаты и открытие подробностей двойным щелчком.
- Обновлён чат: статус отправки у каждого сообщения, выделение текста и Shift+Enter для перехода на новую строку.
- Улучшены рыночные графики: перекрестие, более понятные подсказки и шкала отклонения от рыночной цены.
- Отображение количества предложений по способам оплаты и поиск способов оплаты по стране или валюте.
- Упрощена настройка мостов Tor с использованием Snowflake и пользовательских мостов, включая WebTunnel.
- Отображение ошибок подключения к Monero в нижней панели и уменьшение количества всплывающих окон о подключении.
- Добавлена поддержка программ чтения с экрана и улучшена навигация с клавиатуры.
- Добавлена необязательная настройка программного рендеринга на случай проблем с отображением.
- Обновлена светлая тема, доработаны навигация, таблицы, платёжные инструкции, окна чата, всплывающие окна и уведомления.
- Обновлены переводы.

## _Способы оплаты_

- Добавлено 24 способа оплаты:
  - Африка: M-Pesa; NIP Instant Bank Transfer / OPay / PalmPay.
  - Латинская Америка: Mercado Pago; Mexico/SPEI; Pago Móvil.
  - Азия: GCash; MoMo; QRIS / BI-FAST; Raast / Easypaisa / JazzCash; PayNow / FAST; FPS (Гонконг); DuitNow; PayPay; Kaspi.
  - Европа: BLIK; Vipps MobilePay; TWINT; Wero; MB WAY; переводы на украинские карты.
  - Турция: Papara / FAST.
  - Россия: СБП; перевод на карту «Мир»; ЮMoney.
- Прекращена поддержка Popmoney.
- Поддержка всех способов оплаты через структурированные формы API для доступа с мобильных устройств.

## _Ядро_

- Улучшены скорость запуска, подключение к сид-узлам и восстановление после зависших соединений.
- Обновление сетевых данных и статистики сделок после потери соединения или выхода из режима ожидания.
- Добавлены экспериментальные нативные кошельки Monero.
- Улучшены синхронизация кошелька, обнаружение выплат, восстановление сделок и повторные попытки отправки транзакций после сбоев узла Monero.
- Сохранение зарезервированных средств предложения при инициализации сделки и запрет отмены предложений, уже зарезервированных под сделки.
- Смена пароля стала надёжной, добавлен инструмент для исправления прерванной смены пароля.
- Улучшены резервное копирование аккаунта, обработка прерванного восстановления кошелька и завершение работы.
- Резервные копии кошельков сделок хранятся до финализации выплат.
- Снижено потребление ресурсов процессора и памяти в зашифрованном хранилище, при обработке сетевых данных и статистики сделок.
- Закрытые сделки хранятся в устойчивом к сбоям зашифрованном журнале с дозаписью.
- Исправлены расхождения в количестве исторических сделок и объёме в USD между перезапусками.
- Разрешено отклонение цены до 100%, добавлено предупреждение о противоречивых суммах платежа перед публикацией предложения.
- Возвращён клиент API для командной строки, добавлены фильтрация сделок по статусу и уведомления об оповещениях, jar-файлы демона публикуются вместе с релизами, поддерживается доступ к API через onion-сервис Tor.
- Добавлено руководство пользователя по API, охватывающее настройку, рыночные данные, уведомления о сделках и торговлю с помощью haveno-ts.
- Упакованные Java-архивы стали воспроизводимыми, стандартизированы локаль и кодировка сборки.
- Исправлена установка в Tails после изменений в Tor Proof of Work, улучшена проверка установщика.
- Обновление Monero до v0.18.5.3, monero-java до v0.8.62, Tor до v0.4.9.13, Apache HttpClient до v5.6.4 и Gradle до v8.14.2.

## _Исправления безопасности_

- Усилена проверка участников сделок, отправителей сообщений по спорам, полномочий арбитров и сетевых оповещений.
- Предотвращён откат состояния при повторной отправке сообщений по спорам, пересмотренные решения применяются по их подписанным временным меткам.
- Усилены проверка адреса выплаты и комиссии за транзакцию, подписание аккаунтов и проверка цепочки подписантов.
- Отклонение сетевых сообщений чрезмерного размера и полезной нагрузки с несовпадающими хешами, ограничение запросов на подписание предложений и запросов на сделки от пиров, блокировка пиров, подключённых к неверной сети Haveno.
- Экспорт мастер-сида защищён проверками разблокировки аккаунта и ограничениями частоты запросов, ужесточены права доступа к файлам ключей и резервных копий, конфиденциальные сведения скрываются из сообщений об ошибках, удалена передача файлов журнала в спорах.
- Отклонение сообщений в чате сделки после её завершения, а также между арбитрами и трейдерами.
- Предотвращено извлечение архивов за пределы целевой директории, усилена проверка ключа подписи для обновлений приложения.
- Пароль API требуется до запуска демона, прослушивание ведётся только на localhost, если не задан адрес привязки, неудачные попытки входа ограничиваются по частоте, а встроенный веб-прокси ограничен локальными хостами и источниками.

## _Запуск Haveno_

Для достижения наилучших результатов настоятельно рекомендуется запустить _свой собственный локальный узел Monero_, поскольку сеть Tor может работать медленно и ненадежно при синхронизации с удалёнными узлами Monero.

Haveno можно использовать и в основной сети Monero с помощью сторонних сетей. На данный момент мы официально не поддерживаем никакие конкретные сети. Кроме того, вы можете создать собственную сеть, следуя этому [руководству](https://github.com/haveno-dex/haveno/blob/master/docs/create-mainnet.md).

## _Примечания по установке_

Загрузите и установите Haveno с помощью установщика для вашей операционной системы. Установщик предоставляется сетью, которую вы используете. Вы также можете собрать его из исходного кода, адаптировав эту [инструкцию](https://github.com/haveno-dex/haveno/blob/master/docs/installing.md) под выбранную вами сеть.

### _Windows и Linux_

* Перед запуском программы установки удалите все предыдущие версии Haveno.

### _macOS_

1. Откройте программу установки и перетащите Haveno.app в раздел 'Applications'
2. Откройте окно терминала (cmd + пробел, затем введите 'terminal')
3. Скопируйте и вставьте в окно терминала: `sudo xattr -rd com.apple.quarantine /Applications/Haveno.app` и нажмите Enter
4. Введите пароль
5. Щелкните правой кнопкой мыши на /Applications/Haveno.app > Открыть. При необходимости повторите процедуру, даже если выводится сообщение, что приложение повреждено

### _Tails_

* См. [инструкции](https://github.com/haveno-dex/haveno/tree/master/scripts/install_tails). Сетевым администраторам рекомендуется сделать однострочную команду установки доступной для каждого релиза

### _Директория приложения по умолчанию:_

- Linux: ~/.local/share/Haveno/
- macOS: ~/Library/Application Support/Haveno/
- Windows: ~\AppData\Roaming\Haveno\
