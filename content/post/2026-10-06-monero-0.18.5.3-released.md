## _Обзор_

Это новая версия программного обеспечения Monero 0.18.5.3. Данная версия настоятельно рекомендуется к установке и содержит большое количество исправлений ошибок.

Некоторые особенности новой версии:

- Демон: исправлены зависания P2P-соединений ([#10918](https://github.com/monero-project/monero/pull/10918))
- Демон: восстановлена ретрансляция транзакций после перезапуска ([#10845](https://github.com/monero-project/monero/pull/10845))
- Демон: улучшена обработка ретрансляции блоков ([#11299](https://github.com/monero-project/monero/pull/11299), [#11301](https://github.com/monero-project/monero/pull/11301))
- Демон: улучшена обработка повторных рукопожатий и тайм-аутов ([#11157](https://github.com/monero-project/monero/pull/11157), [#11305](https://github.com/monero-project/monero/pull/11305))
- Демон: лимиты подключений с публичных IPv6-адресов группируются по подсетям /64 ([#11013](https://github.com/monero-project/monero/pull/11013))
- Демон: сброс отклонённых диапазонов блоков от отключившихся узлов ([#11145](https://github.com/monero-project/monero/pull/11145))
- Демон: улучшены сериализация и проверка транзакций ([#11302](https://github.com/monero-project/monero/pull/11302), [#11349](https://github.com/monero-project/monero/pull/11349), [#11360](https://github.com/monero-project/monero/pull/11360), [#11372](https://github.com/monero-project/monero/pull/11372))
- Демон: ограничен размер кэша смещений выходов ([#11303](https://github.com/monero-project/monero/pull/11303))
- Демон: улучшены изменение размера LMDB и обработка транзакций ([#10946](https://github.com/monero-project/monero/pull/10946), [#11159](https://github.com/monero-project/monero/pull/11159), [#11205](https://github.com/monero-project/monero/pull/11205), [#11290](https://github.com/monero-project/monero/pull/11290))
- Демон: `get_transaction_pool` отключён в ограниченном режиме ([#10973](https://github.com/monero-project/monero/pull/10973))
- Демон: улучшена фильтрация данных в целях приватности в ограниченном RPC ([#11034](https://github.com/monero-project/monero/pull/11034), [#11147](https://github.com/monero-project/monero/pull/11147))
- Демон: `get_public_nodes` ограничен узлами публичной зоны ([#11356](https://github.com/monero-project/monero/pull/11356))
- Демон: отклонение отправки блоков с большой глубиной через ограниченный RPC ([#11239](https://github.com/monero-project/monero/pull/11239))
- ZMQ: восстановление после запросов чрезмерного размера ([#10959](https://github.com/monero-project/monero/pull/10959))
- ZMQ: содержимое запросов скрыто из журналов в ограниченном режиме ([#10971](https://github.com/monero-project/monero/pull/10971))
- Кошелёк: улучшена проверка транзакций при холодном подписании и подписании с мультиподписью ([#11192](https://github.com/monero-project/monero/pull/11192), [#11332](https://github.com/monero-project/monero/pull/11332))
- Кошелёк: все копии одноразовых чисел (nonce) мультиподписи удаляются одновременно ([#11331](https://github.com/monero-project/monero/pull/11331))
- Кошелёк: исправлены импорт выходов мультиподписи и обработка обновления ([#11078](https://github.com/monero-project/monero/pull/11078), [#11464](https://github.com/monero-project/monero/pull/11464))
- Кошелёк: ускорено обновление для старых учётных записей ([#10856](https://github.com/monero-project/monero/pull/10856))
- Кошелёк: исправлены устаревшие таблицы переводов после импорта выходов ([#11463](https://github.com/monero-project/monero/pull/11463))
- Кошелёк: исправлена несогласованная обработка публичного ключа транзакции ([#11458](https://github.com/monero-project/monero/pull/11458))
- Кошелёк: проверка области определения образа ключа (key image) в доказательствах резервов ([#11153](https://github.com/monero-project/monero/pull/11153))
- Кошелёк: исправлены отображение и классификация идентификаторов платежа (payment ID) ([#10894](https://github.com/monero-project/monero/pull/10894), [#11461](https://github.com/monero-project/monero/pull/11461))
- Кошелёк: усилена защита от вредоносных удалённых узлов ([#10950](https://github.com/monero-project/monero/pull/10950), [#11320](https://github.com/monero-project/monero/pull/11320), [#11347](https://github.com/monero-project/monero/pull/11347), [#11444](https://github.com/monero-project/monero/pull/11444))
- Кошелёк: требование обязательного SSL сохраняется при разрешении цепочек сертификатов ([#11336](https://github.com/monero-project/monero/pull/11336))
- Кошелёк: улучшена обработка обновления и завершения работы ([#11135](https://github.com/monero-project/monero/pull/11135), [#11151](https://github.com/monero-project/monero/pull/11151), [#11173](https://github.com/monero-project/monero/pull/11173))
- Кошелёк: исправлен бесконечный цикл при оценке транзакций с большим числом выходов ([#11184](https://github.com/monero-project/monero/pull/11184))
- Кошелёк: разбивка полученной суммы остаётся согласованной ([#11449](https://github.com/monero-project/monero/pull/11449))
- RPC кошелька: в `describe_transfer` добавлен вес транзакции ([#11112](https://github.com/monero-project/monero/pull/11112))
- RPC кошелька: улучшена обработка автоматического обновления и завершения работы ([#10955](https://github.com/monero-project/monero/pull/10955), [#11139](https://github.com/monero-project/monero/pull/11139))
- RPC кошелька: `--password` отклоняется при использовании вместе с `--wallet-dir` ([#11258](https://github.com/monero-project/monero/pull/11258))
- Trezor: проверка размера ответа моста перед разбором ([#10989](https://github.com/monero-project/monero/pull/10989))
- RandomX: обновление до v1.2.3 ([#10926](https://github.com/monero-project/monero/pull/10926))
- Предотвращено внедрение записей в журнал через некорректный JSON и HTTP-заголовки ([#11149](https://github.com/monero-project/monero/pull/11149), [#11225](https://github.com/monero-project/monero/pull/11225))
- Исправлено повторное использование HTTP-соединений после разрыва со стороны удалённого узла ([#11115](https://github.com/monero-project/monero/pull/11115))
- Различные исправления ошибок и улучшения

Полный список изменений [выложен на GitHub](https://github.com/monero-project/monero/compare/v0.18.5.1...v0.18.5.3) вместе с [исходным кодом](https://github.com/monero-project/monero/tree/v0.18.5.3).

Подписанный GPG список хешей можно найти по этой ссылке: https://getmonero.org/downloads/hashes.txt. Он является каноническим, а подписи сверяются с соответствующим ключом GPG в исходном коде (в /utils/gpg_keys). Чтобы проверить наверняка, были ли скачанные вами файлы изначально загружены мейнтейнерами, следует проверить как соответствие хешей ваших файлов тем, что указаны в списке, так и соответствие подписи под списком.

В процессе верификации вам помогут эти два руководства: [Verify binaries on Windows (beginner)](https://www.getmonero.org/resources/user-guides/verification-windows-beginner.html) (Проверка двоичных файлов в Windows (для начинающих)) и [Verify binaries on Linux, Mac, or Windows command line (advanced)](https://www.getmonero.org/resources/user-guides/verification-allos-advanced.html) (Проверка двоичных файлов посредством командной строки Linux, Mac или Windows (продвинутый уровень)).
