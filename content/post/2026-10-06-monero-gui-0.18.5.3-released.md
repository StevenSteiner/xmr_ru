## _Обзор_

Это новая версия программного обеспечения Monero GUI 0.18.5.3. Данная версия настоятельно рекомендуется к установке и содержит большое количество исправлений ошибок.

Краткий обзор последней версии CLI можно найти в [предыдущем посте](https://www.getmonero.org/2026/10/06/monero-0.18.5.3-released.html).

Некоторые особенности новой версии:

- Добавлены новые варианты фиатных валют ([#4714](https://github.com/monero-project/monero-gui/pull/4714))
- Исправлена сортировка истории транзакций ([#4693](https://github.com/monero-project/monero-gui/pull/4693))
- Исправлено отображение устаревших транзакций в диалоге подтверждения отправки ([#4690](https://github.com/monero-project/monero-gui/pull/4690), [#4720](https://github.com/monero-project/monero-gui/pull/4720))
- Учётные данные демона теперь привязаны к конкретному соединению ([#4709](https://github.com/monero-project/monero-gui/pull/4709))
- Исправлены обработка прокси SOCKS5 и использование прокси при проверке обновлений ([#4681](https://github.com/monero-project/monero-gui/pull/4681), [#4682](https://github.com/monero-project/monero-gui/pull/4682), [#4707](https://github.com/monero-project/monero-gui/pull/4707), [#4710](https://github.com/monero-project/monero-gui/pull/4710))
- Исправлены обновление курса в фиатной валюте и проверка обновлений в Linux ([#4725](https://github.com/monero-project/monero-gui/pull/4725))
- Сохранение кошелька прерывается, если не удалось установить пароль ([#4645](https://github.com/monero-project/monero-gui/pull/4645))
- Исправлено определение высоты восстановления при вводе дат без дефисов ([#4672](https://github.com/monero-project/monero-gui/pull/4672))
- При проверке подписанных сообщений отображается тип ключа ([#4687](https://github.com/monero-project/monero-gui/pull/4687))
- Улучшено отображение транзакций с несколькими получателями ([#4692](https://github.com/monero-project/monero-gui/pull/4692))
- Суммы в доказательствах резервов отображаются в XMR ([#4719](https://github.com/monero-project/monero-gui/pull/4719))
- Исправлено сканирование QR-кода с экрана в macOS ([#4663](https://github.com/monero-project/monero-gui/pull/4663))
- P2Pool обновлён до v4.18.1 ([#4715](https://github.com/monero-project/monero-gui/pull/4715))
- Мелкие исправления ошибок

Полный список изменений [выложен на GitHub](https://github.com/monero-project/monero-gui/compare/v0.18.5.2...v0.18.5.3) вместе с [исходным кодом](https://github.com/monero-project/monero-gui/tree/v0.18.5.3).


Подписанный GPG список хешей можно найти по этой ссылке: https://getmonero.org/downloads/hashes.txt. Он является каноническим, а подписи сверяются с соответствующим ключом GPG в исходном коде (в /utils/gpg_keys). Чтобы проверить наверняка, были ли скачанные вами файлы изначально загружены мейнтейнерами, следует проверить как соответствие хешей ваших файлов тем, что указаны в списке, так и соответствие подписи под списком.

В процессе верификации вам помогут эти два руководства: [Verify binaries on Windows (beginner)](https://www.getmonero.org/resources/user-guides/verification-windows-beginner.html) (Проверка двоичных файлов в Windows (для начинающих)) и [Verify binaries on Linux, Mac, or Windows command line (advanced)](https://www.getmonero.org/resources/user-guides/verification-allos-advanced.html) (Проверка двоичных файлов посредством командной строки Linux, Mac или Windows (продвинутый уровень)).
